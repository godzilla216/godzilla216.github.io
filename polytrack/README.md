This copy runs without advertising or remote player data transfers.

Online leaderboards, profile uploads, replay uploads/downloads, and verification services are disabled. No persistent player ID is generated or loaded. Scores, custom tracks, settings, and car customization remain stored locally in the browser.

The Discord promotion is removed. Creator and music attribution remain visible. The page restricts network connections to its own origin and blocks embedded frames and objects.

Only compiled game bundles are included in this repository, so the offline changes are applied directly to `dist/main.bundle.js`.
